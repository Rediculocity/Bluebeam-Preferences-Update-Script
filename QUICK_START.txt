WHAT THIS TOOL DOES:

✓ Replaces custom color palette in Bluebeam
✓ Adds missing toolsets / fixes wrong toolset paths
✓ Updates stamp directory (auto-selects best path for you)
✓ Updates template directory (auto-selects best path for you)
✓ Adds missing line sets / fixes wrong paths (every profile)
✓ Adds missing hatch sets / fixes wrong paths (every profile)
✓ Creates automatic backup of every file before changes
✓ Validates saved XML and restores backup if corrupt
